# Бронювання столика через Telegram

Агент пише з твого Telegram-акаунта до одного отримувача. Він просить столик на двох на сьогодні о 17:00 за лондонським часом. Коли менеджер підтверджує бронь, агент дякує та повторює деталі. Для здачі завдання вкажи назву закладу в `RESTAURANT_NAME`. Якщо поле порожнє, агент використає назву, яку менеджер сам згадав у чаті, або звертання «your restaurant».

## Запуск у PyCharm

1. Вибери інтерпретатор проєкту. Для нового клону встанови залежності командою `python -m pip install -r requirements.txt` і скопіюй `.env.example` у `.env`.
2. У `.env` впиши в `TELEGRAM_RECIPIENT` username свого другого акаунта. Заповни `TELEGRAM_API_ID` та `TELEGRAM_API_HASH` із розділу API development tools на [my.telegram.org](https://my.telegram.org).
3. Для локальної обробки залиш `OPENAI_API_KEY=` порожнім. Встанови і запусти [Ollama для Windows](https://ollama.com/download/windows), потім виконай у PowerShell `ollama pull qwen2.5:3b`. Агент автоматично використає цю модель. Іншу встановлену локальну модель можна вибрати через `OLLAMA_MODEL`. Якщо заповниш `OPENAI_API_KEY`, діалог оброблятиме OpenAI через `OPENAI_MODEL`. За бажанням вкажи ім’я гостя в `BOOKING_NAME`.
4. Запусти `agent.py` до 17:00 за Лондоном. Під час першого входу введи в консолі номер акаунта-відправника, код Telegram і, якщо ввімкнено, пароль двоетапної перевірки.
5. Відповідай з другого акаунта як менеджер. Наприклад, запропонуй 17:30, потім погодься на 17:00, запитай ім’я гостя і підтвердь бронювання. Якщо бракує даних гостя, агент поставить тобі запитання в консолі й сам складе відповідь англійською.

Для автоматичної відповіді менеджеру заповни в `.env` поля `BOOKING_NAME` та `BOOKING_PHONE`. Вкажи номер для бронювання з кодом країни. Якщо потрібне поле порожнє, агент запитає його в консолі й запам’ятає введене значення до кінця запуску.

Кожен запуск починає новий діалог. Якщо зв’язок перервався, перед повторним запуском перевір останнє повідомлення в чаті.

## Матеріали для здачі

Після тесту зроби скріншот усієї переписки в Telegram. У консолі агент виведе шлях до журналу `runs/*.jsonl`. Кожен рядок містить час, напрямок, Telegram ID повідомлення, текст, інтерпретацію та рішення. Для GitHub у проєкті є шаблон конфігурації. Локальні ключі, файл сесії Telegram та журнали виключені через `.gitignore`.

## Нотатки про реалізацію

- Розглядав Telegram Bot API, але за умовою першим пише агент.
- Обрав Telethon для входу через особистий акаунт і роботи з приватним чатом.
- Для вільних відповідей менеджера агент використовує локальну модель в Ollama або хмарну модель OpenAI.
- Дату визначає Python через часовий пояс Europe/London.
- Фінальне повідомлення формує код із погоджених деталей, назви закладу та фіксованих параметрів запиту.
- Codex допоміг реалізувати клієнт, інструкції моделі та локальну перевірку.
